Задание 2. Запуск и проверка
Артём Хаматуллин. Распределённый генетический алгоритм, C# / .NET 9.
Два вычислительных HTTP-сервиса и управляющее окно на Avalonia.

1. Подготовка
Нужен .NET SDK 9. При первой сборке нужен интернет для загрузки NuGet-пакетов.
Распакуйте архив. В терминале перейдите в папку ex2, где лежит TspDistributed.sln.
dotnet build TspDistributed.sln -c Release

2. Запуск
Откройте три терминала. В каждом перейдите в ту же папку ex2.
Первый терминал, сервис на порту 5101:
dotnet run --project src/TspWorker -c Release --no-build -- --urls http://127.0.0.1:5101
Второй терминал, сервис на порту 5102:
dotnet run --project src/TspWorker -c Release --no-build -- --urls http://127.0.0.1:5102
Третий терминал, управляющее окно:
dotnet run --project src/TspDistributed.App -c Release --no-build
Оставьте все три процесса запущенными.

3. Проверка в окне
Адреса 127.0.0.1:5101 и 127.0.0.1:5102 уже указаны. Параметры можно не менять.
Нажмите «Старт». В окне появятся маршрут, его длина, график и статус сервисов.
Для другой задачи: «Число городов» = 50, «Сгенерировать», затем «Старт».
«Стоп» завершает поиск и оставляет лучший маршрут на экране.
Для проверки отказа во время поиска нажмите Ctrl+C в одном из сервисов.
Координатор продолжит работу на оставшемся сервисе и покажет ошибку адреса.

4. Тесты
dotnet test TspDistributed.sln -c Release
4 теста: точное решение, совпадение на 1 и 8 потоках, сокращение маршрута,
работа двух HTTP-сервисов с отказом одного из них.
Для тестов запускать сервисы вручную не нужно.

Как распределяется работа
У каждого сервиса своя популяция. Сервисы считают блоки поколений параллельно.
После блока координатор собирает ответы и передаёт лучший маршрут островам.
Размер популяции и лимит поколений в окне задаются на один остров.
Для разных компьютеров: сервису задайте --urls http://0.0.0.0:5101,
а в окне укажите его IP и порт. Порт должен быть доступен по сети.
